# Генератор Gmail — Android-приложение (APK)

Android-обёртка (WebView) для веб-приложения **«Генератор GMail»** от Aspose:
<https://products.aspose.app/email/ru/gmail-generator>

Готовый к установке файл: **`dist/GmailGenerator.apk`** (~80 КБ).

## Что делает приложение

- Открывает генератор временных Gmail-адресов внутри приложения на весь экран.
- Временный адрес вида `вашлогин+псевдоним@gmail.com` создаётся на сайте Aspose —
  письма приходят в настоящий ящик Gmail, а приложение сайта подсказывает,
  как настроить фильтр и отключить адрес.
- Внутренние переходы (`aspose.*`) открываются внутри приложения, внешние
  ссылки — в браузере телефона.
- Кнопка «Назад» листает историю страниц; при повороте экрана страница не
  перезагружается; при загрузке отображается полоса прогресса.

## Установка на телефон

1. Скопируйте `dist/GmailGenerator.apk` на телефон.
2. Откройте файл и разрешите установку из неизвестных источников.
3. Либо через ADB: `adb install dist/GmailGenerator.apk`

Требования: Android 7.0 (API 24) и новее. Приложение подписано по схемам
APK Signature v2/v3 (самоподписанный сертификат, Play Store не требуется).

## Пересборка

```bash
tar xzf build-tools.tar.gz   # распаковать инструменты (~200 МБ)
./build-apk.sh               # собрать и подписать APK
```

Архив **`build-tools.tar.gz`** (~83 МБ) лежит прямо в этом каталоге и содержит
всё необходимое: JRE 25, Apktool 2.9.3, aapt2/aapt, apksigner и Android framework.
Скрипт собирает APK из smali и подписывает его apksigner'ом. По умолчанию
используется демонстрационный ключ (`gmailgen.jks`, пароль `gmailgen123`) — для
собственного релиза задайте переменную `KEY_PASS` и удалите старый `gmailgen.jks`,
ключ сгенерируется заново. Хранить ключ в git не следует (см. `.gitignore`).

Состав архива и примечания — в `build-tools/README.md` внутри архива.
